# Support

Highfloor for Codex is a community project maintained on a best-effort basis.

## Use GitHub issues for

- reproducible installer or updater defects;
- manifest and validation failures;
- unclear or contradictory documentation;
- a skill or agent behavior that violates its published contract;
- compatibility reports with a specific Codex release or surface;
- focused enhancement proposals.

Include version, operating system, Codex surface, destination paths with private
segments redacted, reproduction steps, expected behavior, and observed output.

## Do not use public issues for

- vulnerabilities or exploit details—follow `SECURITY.md`;
- credentials, private repository contents, session transcripts, or personal
  data;
- general OpenAI account, billing, or product support;
- bypassing login, paywalls, CAPTCHA, private networks, or permissions;
- requests to redistribute components outside their upstream license.

## Compatibility

Codex capabilities, model availability, and documented extension paths can
change. A host-specific failure is actionable when the report identifies the
observed Codex version or product surface and separates repository behavior
from host behavior.

Support cannot guarantee access to the model names configured in this
repository.
