# Design Debt

Record intentional exceptions when an issue is deferred, accepted or outside the current patch.

```markdown
- Date:
  Surface:
  Issue:
  Affected users:
  Severity: Critical | Major | Minor
  Why deferred:
  Accepted by:
  Fix:
  Status: Open | Accepted temporarily | Fixed
```

Escalate debt that blocks a primary task, affects accessibility, repeats across components or becomes part of a reusable pattern. Accessibility debt requires explicit user acceptance and must not be buried in a final summary.
