# TypeScript Decision Router

Use the repository's runtime, package manager, compiler and validation stack.

- Untyped input, domain shapes and narrowing: `types-boundaries.md`
- Error translation and Result/exception choices: `errors.md`
- Compiler flags and migration costs: `compiler-safety.md`

Do not treat `any`, assertions, enums or non-null assertions as universal defects. Isolate and justify unsafe boundaries. Do not change compiler configuration as unrelated cleanup.
