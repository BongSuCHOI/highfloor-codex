# Slopslap Reference Matrix — Schema and Contract (Plan B)

Pass audit findings through a pre-collected reference matrix to select one
coherent direction—color, grid, and typography strategy—rather than applying
fragmented fixes, then transform decisively. Collect every value from real
source evidence; do not type values by hand.

## Cell key

```text
cellKey = <tell>            # taxonomy id; replacement types only, no matrix for deletion types
        + "__" + <section>  # hero | pricing | features | faq | footer | nav | cta | generic
        + "__" + <bold>     # on | off
```

- C (spacing), D (type), and E (color) are page-global contracts and usually
  use `section=generic`.
- B (grid and section layout) benefits from a concrete `section` value such as
  hero or pricing.
- Lookup is deterministic: finding → normalize `cellKey` → longest-prefix plus
  alias match.

## Answer-unit schema

```jsonc
{
  "id": "<unit-id>",
  "cellKeys": ["unscaled-spacing-ladder__generic__off", ...],  // one unit may cover multiple cells
  "styleTag": "minimal|editorial|swiss-grid|classic-serif|tech-dark|brutalist|playful|organic",
  "direction": "short human-readable direction label; execution uses only numeric contract values",
  "contract": {                     // measured values; execution snap target
    "spacingLadder_px": [ ... ],    // measured spacing histogram from collected sites → ladder
    "typeScale_px": [ ... ],        // measured font-size scale
    "typeRatio": 1.25,              // derived modular ratio
    "palette": { "accent": ["#..."], "neutralRamp": ["#..."], "semantic": {...} },
    "measure_ch": [60,75],
    "gridRatios": ["1fr 1fr", "3fr 2fr"],
    "fontRoles": { "display": "...", "body": "...", "mono": "..." }
  },
  "evidence": { "screenshot": "shots/<id>.webp", "sourceUrl": "https://...", "capturedAt": "<ISO>", "license": "public-observed" },
  "check": "predicate measured from source to prove this unit was applied"
}
```

## Mode gate: prevent conflict with the reductive contract

Slopslap defaults to **reductive** work: delete before shrink before replace,
without broad redesign. Plan B transform is a separate mode.

- `mode=reductive` (default): use the existing pipeline. The matrix is
  report-only reference; execution derives values from the target.
- `mode=transform` (explicit selection): pass all audit findings through the
  matrix, select **one coherent direction set**, and have every area executor
  consume the same contract. Copy, information, and order remain immutable even
  during redesign.

## Red team: design-time questions resolved before execution

1. **Answer sheet collapsing into a median house style:** require at least three
   units per cell and at least three distinct `styleTag` values. Derive the
   choice from target content, `BOLD`, and the declared concept. A decision based
   only on avoidance is invalid under the taxonomy contract. Cap one source site
   at 10% and one `styleTag` at 35%.
2. **Transform versus reductive conflict:** separate them with an explicit mode
   gate. No hidden redesign.
3. **False saturation:** saturation means the coverage report has zero missing
   cells, not that it feels complete. Use live fallback for a missing cell, then
   incorporate it.
4. **License:** borrow measured values and structural patterns only. Do not copy
   markup or assets. Record source provenance in `evidence`.
5. **Freshness:** the matrix is generated by a regeneration script. Re-collect
   after material source changes.

## Median guard: final Phase 4 test

Pass two stylistically different targets through the same matrix. The two
results must remain different. If they converge, the answer sheet has become a
single prescribed answer and Red Team item 1 has failed.
