# pwndbg

Use pwndbg only as an optional GDB view for authorized native debugging.

Choose it when register, stack, heap, memory-map or instruction context materially helps. Preserve the original crash input and executable identity. Treat convenience annotations as views over GDB state, not independent proof.

Do not install or change a system debugger configuration automatically. If unavailable, explain the capability and propose an exact installation command or continue with LLDB/GDB when sufficient.
