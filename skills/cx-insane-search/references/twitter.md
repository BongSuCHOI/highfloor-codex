# X/Twitter Public Access

Use built-in web search to discover public post URLs. For a known public post, prefer public publishing/syndication representations implemented by engine Phase 0, such as oEmbed or the syndication result endpoint.

Public profile syndication can expose only a limited recent set and may omit small or new accounts. Engagement counts and endpoint shapes are drift-prone; verify them at use time and report the observation time.

Do not log in, reuse cookies, scrape a private account, bypass age/region/permission gates or claim unavailable replies/metrics.
