# Structured Page Metadata

Use OGP, Twitter Card, JSON-LD and ordinary metadata when the body is unavailable but the page still exposes public descriptive data.

Useful fields include canonical URL, title, description, author, publication/update time, content type and image URL. Validate that metadata belongs to the requested page and distinguish publisher-provided metadata from extracted body text.

Metadata is a fallback summary, not proof of the full article, comments or current engagement.
