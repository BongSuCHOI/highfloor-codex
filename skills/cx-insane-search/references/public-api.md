# Public API Selection

Prefer a documented public API when it directly answers the request with less ambiguity than scraping. Typical Phase 0 families include GitHub, Hacker News, Bluesky/AT Protocol, Mastodon, arXiv, CrossRef, Stack Exchange, Wikipedia, npm, PyPI and Open Library.

Check current official documentation for drift-prone parameters, limits and schemas. Use only the minimal endpoint and fields needed. A public API does not authorize enumeration of private, deleted or permission-gated data.
