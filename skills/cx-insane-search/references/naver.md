# Naver Public Routes

Use only pages and endpoints available without login:

- built-in web search for discovery;
- public mobile or service pages when they expose the same content;
- documented public search/API endpoints when credentials are already supplied by the user and use is authorized;
- RSS or structured metadata when the service publishes it.

Do not spoof an authenticated identity, extract Naver cookies, infer private cafe/blog content or automate CAPTCHA. Endpoint behavior is drift-prone; validate the selected public path at use time.
